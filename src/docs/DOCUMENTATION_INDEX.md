### For Quick Reference
- Bookmark this index file
- Use keyboard shortcut Cmd+F / Ctrl+F to search
- Click links to jump between documents

### For Learning
- Read documents in "Reading Tracks" order
- Open multiple doc tabs to reference simultaneously
- Review component files after reading architectural docs

### For Troubleshooting
1. Check the relevant "Troubleshooting" section
2. Search documentation using Cmd+F / Ctrl+F

4. Check browser console (F12) for error messages

### For Customization
1. Read examples in QUICK_START.md
2. Find the relevant section in MIGRATION_GUIDE.md
3. Locate the relevant file in src/ folder
4. Make changes and test with `bun run dev`
